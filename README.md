# 🛒 Flipkart Product Detail Page (OPPO Find X8)

An enterprise-grade, accessible e-commerce product detail page clone built with responsive HTML5, CSS3, and JavaScript.

## 🌟 Key Features

- **Product Gallery**: Interactive thumbnail image selector with wishlist toggle.
- **Variant Selector**: Switch between color choices (Star Grey, Space Black) and memory variants (12GB / 16GB).
- **Pincode Delivery Checker**: Instant client-side validation for delivery estimates.
- **Cart Counter & Toast Notifications**: Real-time feedback when items are added to cart.
- **SEO & Rich Snippets**: Full JSON-LD `Product`, `AggregateRating`, and `Offer` schema implementation.
- **Accessibility & Focus States**: Accessible buttons, ARIA labels, and WCAG-compliant color contrast.

## 📁 File Structure

- `index.html` — Full product detail view with interactive components
- `styles.css` — Modular design system matching Flipkart's UI guidelines
- `404.html` — Custom 404 page
